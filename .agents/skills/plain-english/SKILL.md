name: plain-english
description: Write, rewrite, or review text against plain English standards ISO 24495-1. Use this skill whenever the output is intended for a non-specialist reader, or whenever the user wants existing prose made clearer. Trigger on "plain English", "plain language", "make this clearer", or "simplify this".
---

Write in plain English to ISO 24495-1 principles:

- Average sentence length 15–20 words, maximum 25.
- Active voice. Verbs, not nominalisations.
- Everyday words. Define or cut jargon.
- Main point first, then supporting detail.
- Address the reader as "you".
- One idea per sentence.

Do not simplify by removing necessary information.
If a concept is genuinely complex, explain it in more words rather than fewer.
